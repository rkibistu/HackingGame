Usage: sqlmap [OPTIONS]

-u <URL>         : target URL.
--tables         : enumerate DBMS database tables.
--columns        : enumerate DBMS database table columns.
--help           : show this help.
--version        : show version.

Example:
$ sqlmap --tables --columns -u <URL> 
$ sqlmap -u https://pc-potato.ro?name
$ sqlmap --version
$ sqlmap --help
